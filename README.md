# Real-Time Chat Interface

## About
A frontend-only chat application built using HTML, CSS, and JavaScript. Users can send messages and receive automated replies from a simple chatbot.

## Features
- Send and display messages instantly
- Different styles for sent and received messages
- Save chat history using localStorage
- Display message timestamps
- Simple chatbot with predefined responses
- Smooth scrolling and animations
- Responsive chat interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Files
- `index.html` — Chat interface structure
- `style.css` — Chat interface styling
- `script.js` — Chat functionality and chatbot responses

## Note
This is a frontend-only project. The chatbot uses predefined responses and does not communicate with real users.
